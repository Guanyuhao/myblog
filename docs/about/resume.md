## 专业概述

现任创业公司 Tech Lead，负责 SocialFi、HealthFi 两条业务线的技术决策与端到端交付。具备从客户端、服务端到区块链的跨技术栈实践能力，能够围绕商业目标完成需求判断、架构设计、成本控制、系统上线及持续运营。

曾任职于字节跳动飞书 HCM、比特大陆 AntAlpha，兼具大型企业复杂业务系统建设经验与创业环境下的全链路交付能力。

技术重点涵盖交易结算、资金对账、智能合约集成、跨端架构、弱网通信及 BLE 智能硬件接入。注重技术方案与业务阶段匹配，以交付质量、运行稳定性和商业闭环衡量技术产出。

- **复杂场景攻坚：** WebSocket 弱网恢复、跨端数据一致性、BLE 多型号设备适配及健康数据校验。

#### 项目一｜SocialFi 社交与链上交易平台

**技术体系：** Flutter、Vue、Next.js、Java、Go、Node.js、MySQL、WebSocket、智能合约、DEX。

1. **业务架构：** 将社交 IM、会员权益、交易聚合、手续费结算及收益分配整合为完整业务链路，负责模块边界、接口协议及联调顺序。协调 8+ 仓库的依赖与交付。
2. **交易聚合：** 实现客户端 / SDK 报价参数处理、服务层交易校验与手续费治理、交易执行结果追踪及事件输出；引入费率变更 24 小时延迟生效和撤销机制。
3. **资金与结算：** 结合链上交易事件建立业务收入记录，按 task_id 管理收益发放；通过收入事实、收益流水、待发放余额、发放结果及交易凭证进行多层核对，异常进入人工处理流程。
4. **可靠性治理：** 处理并发与重复请求、价格偏差、资金操作审计及弱网交易确认；交易模块完成 35 项测试验证。
5. **客户端与运营：** 交付 Flutter iOS / Android 社交与账户功能，基于 WSS 心跳重连、HTTP 降级及可重试确认机制提高弱网可用性；建设用户、内容与资金运营后台，资金类操作二次确认并留痕。
6. **工程化：** 基于 MinIO 实现多端配置与资源统一发布，保留版本回滚机制，降低跨端配置不一致风险。

#### 项目二｜HealthFi 智能穿戴与健康激励平台

**技术体系：** Flutter、Java、Node.js、BLE、MySQL、H5、腾讯云 IM。

1. **商业链路：** 完成智能手表购买流程，覆盖收货地址、在线支付、服务端订单确认、设备编号分配及用户设备绑定。
2. **硬件集成：** 适配 F530Pro（Veepoo）、S191（YCBT）两类智能手表，处理 BLE 连接及健康数据同步。
3. **数据治理：** 对步数、卡路里、距离等 8 类健康指标进行按天聚合，建立上报校验与激励资格判定的隔离机制。
4. **激励结算：** Java 服务负责资格判定，Node.js 服务执行积分发放；通过任务幂等与异常处理机制降低重复发放风险。
